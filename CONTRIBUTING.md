# Guia de Contribuição

Obrigado por estar interessado em contribuir! Aqui estão as diretrizes:

## Como Contribuir

1. **Fork o repositório** e clone para sua máquina local
2. **Crie uma branch** para sua feature: `git checkout -b minha-feature`
3. **Commit suas mudanças**: `git commit -m "Descrição clara da mudança"`
4. **Push para a branch**: `git push origin minha-feature`
5. **Abra um Pull Request** com descrição detalhada

## Padrões de Código

- Siga as convenções de nomenclatura do projeto
- Adicione testes para novas funcionalidades
- Mantenha a documentação atualizada

## Relatar Problemas

Use a seção de Issues para reportar bugs ou sugerir melhorias com o máximo de detalhes possível.

## Código de Conduta

Seja respeitoso e inclusivo com todos os contribuidores.

Obrigado pela contribuição! 🎉
